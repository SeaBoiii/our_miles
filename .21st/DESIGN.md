# Our Miles design context

Selected direction: **Field Notes**. A personal, editorial travel instrument for Aleem and Nurul, centered on a fast card decision.

Family resemblance: local Instrument Serif and ivory from `our_flight` / `our_gallery`. Forest green marks actions and the winner. Use typography, whitespace and sparse dividers before containers. Four primary destinations: Home, What Card?, Wallet, Activity. Goals and Bonuses are secondary, reachable from relevant content.

Framework: Next.js, React, strict TypeScript, Tailwind v4. Radix Dialog provides sheet behavior. Motion uses reduced-motion-aware lightweight state transitions. Original route mark and vector landscape; no external media dependency.

Canonical tokens and interaction patterns: [docs/DESIGN_SYSTEM.md](../docs/DESIGN_SYSTEM.md). Exploration rationale: [docs/DESIGN_RESEARCH.md](../docs/DESIGN_RESEARCH.md). Actual rendered quality gate: [docs/DESIGN_REVIEW.md](../docs/DESIGN_REVIEW.md).

Preserve ownership, explicit uncertainty, current cap quantities, immutable recorded explanations and demo isolation. Never rank by headline earn alone or introduce decorative dashboard conventions.
